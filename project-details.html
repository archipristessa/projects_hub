Описание проекта

Создать веб-приложение, которое позволит студентам легко находить друг друга для совместной работы над проектами на основе общих интересов и комплементарных навыков.

Цели:

  • Централизованная платформа для поиска команды
  • Упрощение процесса формирования проектных групп
  • Повышение эффективности студенческих проектов

Ожидаемые результаты:

  • Работающее веб-приложение
  • Документация по проекту
  • Развернутая система на сервере
